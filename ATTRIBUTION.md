# Attribution

`brain_coverage_dseg.py` and `brain_coverage_dseg_sessions.py` (in
`scripts/`) contain code adapted from `advanced-brain-coverage.py` in
DCAN-Labs' `brain_coverage` project.

- Upstream source: https://github.com/DCAN-Labs/brain_coverage

## Modifications from the upstream script

1. **Imaging modality change (BOLD fMRI → DWI)**
   - The upstream script computes brain coverage for task-based BOLD fMRI
     images (`*_task-*_run-*_bold.nii.gz`).
   - This implementation operates on qsiprep-preprocessed diffusion data
     (`*_space-ACPC_desc-preproc_dwi.nii.gz`).
   - Coverage is computed once per subject (or per subject/session) rather
     than per task/run.
2. **Configuration-driven execution**
   - The upstream script is fully CLI-driven using `argparse`.
   - This implementation replaces CLI arguments with a centralized `CONFIG`
     block specifying dataset paths, qsiprep version, output locations, and
     runtime options.
   - This change favors reproducibility and dataset-specific deployment over
     general-purpose CLI flexibility.
3. **Removal of participants.tsv read/write logic**
   - The upstream script reads and updates a BIDS `participants.tsv` file,
     adding multiple `bc_<task>_run-XX` columns.
   - This implementation does not modify `participants.tsv`. Output is
     written to a standalone CSV containing `participant_id` plus one
     coverage column per region mask.
4. **Simplified subject/session handling**
   - The upstream script supports explicit subject and session selection,
     wildcard matching, and multi-session datasets via CLI flags.
   - This implementation auto-discovers subjects (and, in the sessions
     variant, sessions) directly from the qsiprep output directory
     structure, using a fixed file-discovery pattern for the preprocessed
     DWI file.
5. **Subject-specific ACPC-space mask usage**
   - The upstream script accepts an arbitrary MNI mask at runtime.
   - This implementation uses subject-specific ACPC-space brain coverage
     masks, generated by the companion `apply_dseg_masks*.sh` scripts, with
     deterministic filenames derived from the subject ID (and session,
     where applicable). This ensures spatial alignment between the
     diffusion data and each mask.
6. **Refactored path and intermediate file management**
   - All filesystem paths are centralized in the `CONFIG` block.
     Intermediate files are written to a dataset-specific working directory
     rather than a generic temporary location.
   - Intermediate files are automatically removed unless explicitly
     retained.
7. **Simplified output metric**
   - The upstream script produces task- and run-specific coverage columns.
     This implementation produces one coverage column per region mask,
     reflecting diffusion brain coverage rather than task-level fMRI
     coverage.
8. **Script renaming**
   - The scripts have been renamed from the upstream naming convention to
     `brain_coverage_dseg.py` / `brain_coverage_dseg_sessions.py` to reflect
     their diffusion-specific, segmentation-based scope.
